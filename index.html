Como funciona o compartilhamento
Os dados ficam no localStorage do navegador. Para ambos verem os gastos, abra este arquivo HTML no mesmo computador em abas diferentes, ou use qualquer solução de sync de pasta (Google Drive, OneDrive, iCloud Drive) salvando o casal-em-dia.html numa pasta compartilhada.

Uma versão com Firebase (banco em nuvem real) pode ser gerada a partir deste código.
